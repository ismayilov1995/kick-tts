# Kick TTS v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-executable desktop app that reads selected Kick.com events aloud through an OBS Browser Source, remembers every viewer in a local SQLite DB, computes a loyalty score, and speaks milestone template lines. The architecture must let an LLM responder plug in later.

**Architecture:** A Bun + TypeScript local server on `127.0.0.1:7777`. Kick events arrive over Pusher and flow through Normalizer → Store (SQLite) → Filter → Responders (direct + templates) → Safety → Voice (OS TTS → WAV) → priority queue → overlay page (WebSocket + `<audio>`). Every layer is a small module with a pure, unit-tested core; `app.ts` wires them together and `server.ts` exposes HTTP/WS.

**Tech Stack:** Bun ≥ 1.3 (`bun:sqlite`, `Bun.serve` routes + HTML imports, `bun build --compile`, `bun test`), TypeScript, macOS `say`, Windows PowerShell `System.Speech`. No runtime npm dependencies.

**Spec:** `docs/superpowers/specs/2026-11-23-kick-tts-design.md`

**Facts verified on 2026-11-23 (do not re-research):**
- `POST https://web.kick.com/api/v1/realtime/connection` returns `{"data":{"connections":[{"credentials":{"app_key":"34bf7a0ff419a2a775b9","cluster":"us2"},"provider":"pusher"}],"mode":"websocket"},"message":"success"}`.
- `GET https://kick.com/api/v2/channels/xqc` returned 200 from curl; `id` and `chatroom.id` are numbers.
- `GET https://kick.com/stream/livestreams/en?page=1&limit=3&sort=desc` → `data[0].channel.slug`.
- macOS: `printf 'text' | say -v 'Yelda (Turkish (Türkiye))' --file-format=WAVE --data-format=LEI16@22050 -o a.wav -f -` writes a RIFF WAV. `say -v '?'` prints lines like `Yelda (Turkish (Türkiye)) tr_TR    # ...` (single space before the locale, duplicates possible) and `Milena              ru_RU    # ...`.

```ts
const EMOTE = /\[emote:\d+:[^\]]*\]/g;
const LINK = /(?:https?:\/\/|www\.)\S+|\b[\w-]+(?:\.[\w-]+)*\.(?:com|net|org|io|gg|tv|ru|az|tr|me|ly|co|xyz|app|dev)\b\S*/gi;
const REPEAT = /(.)\1{3,}/gu;

export const hasCyrillic = (s: string): boolean => /[а-яё]/i.test(s);

export const csv = (s: string): string[] =>
  s.split(',').map((x) => x.trim().toLowerCase()).filter(Boolean);

/** Removes emotes and links, shortens "aaaaaa" to "aaa", collapses spaces, cuts to maxLength code points. */
export function cleanText(input: string, maxLength: number): string {
  const s = input.replace(EMOTE, ' ').replace(LINK, ' ').replace(REPEAT, '$1$1$1').replace(/\s+/g, ' ').trim();
  return [...s].slice(0, maxLength).join('').trim();
}
```

```ts
export const WEIGHTS = { day: 10, streak: 5, msg: 0.2, kick: 0.5, sub: 50, giftSub: 25, redemption: 2 } as const;
export const DAILY_MSG_CAP = 30;

const LEVELS: [number, string][] = [
  [1500, '👑 Əfsanə'],
  [600, '💎 Sadiq'],
  [200, '⭐ Daimi'],
  [50, '👋 Tanış'],
  [0, '🌱 Yeni'],
];

export type Stats = {
  daysActive: number;
  streak: number;
  countedMsgs: number;
  kicksTotal: number;
  subs: number;
  giftSubs: number;
  redemptions: number;
};

export function computeScore(s: Stats): number {
  const raw =
    s.daysActive * WEIGHTS.day + s.streak * WEIGHTS.streak + s.countedMsgs * WEIGHTS.msg +
    s.kicksTotal * WEIGHTS.kick + s.subs * WEIGHTS.sub + s.giftSubs * WEIGHTS.giftSub + s.redemptions * WEIGHTS.redemption;
  return Math.round(raw * 10) / 10;
}

export function levelFor(score: number): string {
  return LEVELS.find(([min]) => score >= min)![1];
}

/** Local calendar day, 'YYYY-MM-DD'. */
export function dayKey(ts: number): string {
  const d = new Date(ts);
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
}

function prevDayKey(key: string): string {
  const [y, m, d] = key.split('-').map(Number);
  return dayKey(new Date(y, m - 1, d - 1).getTime());
}

export type DayState = { lastActiveDay: string | null; streak: number; daysActive: number; msgsToday: number };

export function advanceDay(prev: DayState, today: string): DayState {
  if (prev.lastActiveDay === today) return prev;
  const streak = prev.lastActiveDay === prevDayKey(today) ? prev.streak + 1 : 1;
  return { lastActiveDay: today, streak, daysActive: prev.daysActive + 1, msgsToday: 0 };
}
```

```ts
import type { KickEvent } from '../types';

/** Event names whose payload shape was never seen live. Their raw payload is always logged. */
export const UNVERIFIED = new Set(['KicksGifted', 'SubscriptionEvent', 'ChannelSubscriptionEvent', 'GiftedSubscriptionsEvent']);

const str = (v: unknown): string | undefined => (typeof v === 'string' ? v : undefined);
const num = (v: unknown): number | undefined =>
  typeof v === 'number' && Number.isFinite(v) ? v
    : typeof v === 'string' && v.trim() !== '' && Number.isFinite(Number(v)) ? Number(v)
    : undefined;

export const shortName = (event: string): string => event.replace(/^App\\Events\\/, '');

export function userKey(id: unknown, username: string): string {
  const n = num(id);
  return n !== undefined ? `kick:${n}` : `kick:name:${username.toLowerCase()}`;
}

/** Pusher sends `data` as a JSON string inside the JSON frame. */
export function parseData(data: unknown): any {
  if (typeof data !== 'string') return data;
  try {
    return JSON.parse(data);
  } catch {
    return null;
  }
}

/** Returns null for events we do not read or cannot parse. */
export function normalize(event: string, data: any, channelId: string, ts = Date.now()): KickEvent | null {
  if (!data || typeof data !== 'object') return null;
  const base = { platform: 'kick' as const, channelId, raw: data, ts };
  switch (shortName(event)) {
    case 'ChatMessageEvent': {
      const username = str(data.sender?.username);
      const text = str(data.content);
      if (!username || text === undefined) return null;
      return { ...base, type: 'chat', userId: userKey(data.sender?.id, username), username, text };
    }
    case 'RewardRedeemedEvent': {
      const username = str(data.username);
      const rewardTitle = str(data.reward_title);
      if (!username || !rewardTitle) return null;
      return { ...base, type: 'reward', userId: userKey(data.user_id, username), username, rewardTitle, text: str(data.user_input) };
    }
    case 'KicksGifted': {
      const username = str(data.sender?.username) ?? str(data.username);
      if (!username) return null;
      const gift = data.gift ?? {};
      return {
        ...base, type: 'kicks', userId: userKey(data.sender?.id, username), username,
        amount: num(gift.amount) ?? num(data.amount), text: str(gift.message) ?? str(data.message),
      };
    }
    case 'SubscriptionEvent':
    case 'ChannelSubscriptionEvent': {
      const username = str(data.username) ?? str(data.user?.username);
      if (!username) return null;
      return { ...base, type: 'sub', userId: userKey(data.user_id ?? data.user?.id, username), username, amount: num(data.months) };
    }
    case 'GiftedSubscriptionsEvent': {
      const username = str(data.gifter_username) ?? str(data.gifter?.username);
      if (!username) return null;
      const n = Array.isArray(data.gifted_usernames) ? data.gifted_usernames.length : num(data.quantity);
      return { ...base, type: 'giftsub', userId: userKey(data.gifter_id ?? data.gifter?.id, username), username, amount: n ?? 1 };
    }
    default:
      return null;
  }
}
```

```ts
import { Database } from 'bun:sqlite';
import type { KickEvent, UserContext } from '../types';
import { advanceDay, computeScore, DAILY_MSG_CAP, dayKey, levelFor } from '../loyalty';

const SCHEMA = `
CREATE TABLE IF NOT EXISTS users (
  id TEXT PRIMARY KEY, username TEXT NOT NULL, first_seen INTEGER NOT NULL, last_seen INTEGER NOT NULL);
CREATE INDEX IF NOT EXISTS users_lower_name ON users (lower(username));
CREATE TABLE IF NOT EXISTS channel_users (
  channel_id TEXT NOT NULL, user_id TEXT NOT NULL,
  msg_count INTEGER NOT NULL DEFAULT 0, msgs_today INTEGER NOT NULL DEFAULT 0, counted_msgs INTEGER NOT NULL DEFAULT 0,
  days_active INTEGER NOT NULL DEFAULT 0, streak INTEGER NOT NULL DEFAULT 0, last_active_day TEXT,
  kicks_total REAL NOT NULL DEFAULT 0, subs INTEGER NOT NULL DEFAULT 0, gift_subs INTEGER NOT NULL DEFAULT 0,
  redemptions INTEGER NOT NULL DEFAULT 0, score REAL NOT NULL DEFAULT 0, level TEXT NOT NULL,
  blocked INTEGER NOT NULL DEFAULT 0, first_seen INTEGER NOT NULL, last_seen INTEGER NOT NULL,
  PRIMARY KEY (channel_id, user_id));
CREATE TABLE IF NOT EXISTS events (
  id INTEGER PRIMARY KEY, channel_id TEXT NOT NULL, user_id TEXT NOT NULL, type TEXT NOT NULL,
  text TEXT, amount REAL, spoken INTEGER, skip_reason TEXT, raw_json TEXT, ts INTEGER NOT NULL);
CREATE INDEX IF NOT EXISTS events_user ON events (channel_id, user_id, ts);
CREATE INDEX IF NOT EXISTS events_ts ON events (channel_id, ts)
`;

const RAW_TTL_MS = 7 * 86_400_000;
const USER_COLS = 'cu.user_id, u.username, cu.score, cu.level, cu.msg_count, cu.days_active, cu.streak, cu.blocked';

type Row = {
  channel_id: string; user_id: string; msg_count: number; msgs_today: number; counted_msgs: number;
  days_active: number; streak: number; last_active_day: string | null; kicks_total: number; subs: number;
  gift_subs: number; redemptions: number; score: number; level: string; blocked: number; first_seen: number; last_seen: number;
};

export type UserRow = {
  user_id: string; username: string; score: number; level: string;
  msg_count: number; days_active: number; streak: number; blocked: number;
};

export type Profile = Row & { username: string; recent: { text: string; ts: number }[] };

export class Store {
  readonly db: Database;

  constructor(path = ':memory:') {
    this.db = new Database(path, { create: true });
    this.db.run('PRAGMA journal_mode = WAL');
    for (const stmt of SCHEMA.split(';').map((s) => s.trim()).filter(Boolean)) this.db.run(stmt);
  }

  /** Events without a numeric id (e.g. subscriptions) reuse the id of a known user with the same name. */
  resolveUserId(e: Pick<KickEvent, 'userId' | 'username'>): string {
    if (!e.userId.startsWith('kick:name:')) return e.userId;
    const hit = this.db
      .query<{ id: string }, [string]>("SELECT id FROM users WHERE lower(username) = ? AND id NOT LIKE 'kick:name:%' ORDER BY last_seen DESC LIMIT 1")
      .get(e.username.toLowerCase());
    return hit?.id ?? e.userId;
  }

  /** Stores the event, updates the viewer's stats and returns the context responders need. */
  record(input: KickEvent): { eventId: number; ctx: UserContext } {
    return this.db.transaction(() => {
      const e = { ...input, userId: this.resolveUserId(input) };
      const before = this.row(e.channelId, e.userId);
      const day = advanceDay(
        {
          lastActiveDay: before?.last_active_day ?? null,
          streak: before?.streak ?? 0,
          daysActive: before?.days_active ?? 0,
          msgsToday: before?.msgs_today ?? 0,
        },
        dayKey(e.ts),
      );
      const isChat = e.type === 'chat';
      const msgsToday = day.msgsToday + (isChat ? 1 : 0);
      const msgCount = (before?.msg_count ?? 0) + (isChat ? 1 : 0);
      const stats = {
        daysActive: day.daysActive,
        streak: day.streak,
        countedMsgs: (before?.counted_msgs ?? 0) + (isChat && msgsToday <= DAILY_MSG_CAP ? 1 : 0),
        kicksTotal: (before?.kicks_total ?? 0) + (e.type === 'kicks' ? e.amount ?? 0 : 0),
        subs: (before?.subs ?? 0) + (e.type === 'sub' ? 1 : 0),
        giftSubs: (before?.gift_subs ?? 0) + (e.type === 'giftsub' ? e.amount ?? 1 : 0),
        redemptions: (before?.redemptions ?? 0) + (e.type === 'reward' ? 1 : 0),
      };
      const score = computeScore(stats);
      const level = levelFor(score);
      const firstSeen = before?.first_seen ?? e.ts;
      const blocked = before?.blocked ?? 0;

      this.db
        .query(`INSERT INTO users (id, username, first_seen, last_seen) VALUES (?, ?, ?, ?)
          ON CONFLICT(id) DO UPDATE SET username = excluded.username, last_seen = excluded.last_seen`)
        .run(e.userId, e.username, e.ts, e.ts);
      this.db
        .query(`INSERT OR REPLACE INTO channel_users (channel_id, user_id, msg_count, msgs_today, counted_msgs, days_active,
          streak, last_active_day, kicks_total, subs, gift_subs, redemptions, score, level, blocked, first_seen, last_seen)
          VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`)
        .run(e.channelId, e.userId, msgCount, msgsToday, stats.countedMsgs, stats.daysActive, stats.streak,
          day.lastActiveDay, stats.kicksTotal, stats.subs, stats.giftSubs, stats.redemptions, score, level, blocked, firstSeen, e.ts);
      const res = this.db
        .query('INSERT INTO events (channel_id, user_id, type, text, amount, raw_json, ts) VALUES (?, ?, ?, ?, ?, ?, ?)')
        .run(e.channelId, e.userId, e.type, e.text ?? e.rewardTitle ?? null, e.amount ?? null, JSON.stringify(e.raw ?? null), e.ts);
      const { n } = this.db
        .query<{ n: number }, [string, string, number]>(
          "SELECT count(*) AS n FROM events WHERE channel_id = ? AND user_id = ? AND type = 'chat' AND ts > ?")
        .get(e.channelId, e.userId, e.ts - 60_000)!;

      return {
        eventId: Number(res.lastInsertRowid),
        ctx: {
          userId: e.userId, username: e.username, level, score, msgCount,
          daysActive: stats.daysActive, streak: stats.streak, firstSeen, lastSeen: e.ts,
          kicksTotal: stats.kicksTotal, subs: stats.subs, giftSubs: stats.giftSubs, redemptions: stats.redemptions,
          blocked: blocked === 1, msgsLastMinute: n,
          recentMessages: this.recent(e.channelId, e.userId, 20),
          prev: before ? { msgCount: before.msg_count, streak: before.streak, level: before.level, lastSeen: before.last_seen } : null,
        },
      };
    })();
  }

  markSpoken(eventId: number, spoken: boolean, reason: string | null = null): void {
    this.db.query('UPDATE events SET spoken = ?, skip_reason = ? WHERE id = ?').run(spoken ? 1 : 0, reason, eventId);
  }

  recent(channelId: string, userId: string, limit: number): { text: string; ts: number }[] {
    return this.db
      .query<{ text: string; ts: number }, [string, string, number]>(
        "SELECT text, ts FROM events WHERE channel_id = ? AND user_id = ? AND type = 'chat' AND text IS NOT NULL ORDER BY ts DESC, id DESC LIMIT ?")
      .all(channelId, userId, limit);
  }

  top(channelId: string, limit = 20): UserRow[] {
    return this.db
      .query<UserRow, [string, number]>(`SELECT ${USER_COLS} FROM channel_users cu JOIN users u ON u.id = cu.user_id
        WHERE cu.channel_id = ? ORDER BY cu.score DESC LIMIT ?`)
      .all(channelId, limit);
  }

  search(channelId: string, q: string): UserRow[] {
    const like = q.toLowerCase().replace(/[\\%_]/g, '\\$&') + '%';
    return this.db
      .query<UserRow, [string, string]>(`SELECT ${USER_COLS} FROM channel_users cu JOIN users u ON u.id = cu.user_id
        WHERE cu.channel_id = ? AND lower(u.username) LIKE ? ESCAPE '\\' ORDER BY cu.score DESC LIMIT 20`)
      .all(channelId, like);
  }

  profile(channelId: string, userId: string): Profile | null {
    const row = this.db
      .query<Row & { username: string }, [string, string]>(
        'SELECT cu.*, u.username FROM channel_users cu JOIN users u ON u.id = cu.user_id WHERE cu.channel_id = ? AND cu.user_id = ?')
      .get(channelId, userId);
    return row ? { ...row, recent: this.recent(channelId, userId, 50) } : null;
  }

  setBlocked(channelId: string, userId: string, blocked: boolean): void {
    this.db.query('UPDATE channel_users SET blocked = ? WHERE channel_id = ? AND user_id = ?').run(blocked ? 1 : 0, channelId, userId);
  }

  /** "Məlumatı sil": removes the viewer from this channel, and entirely if no other channel knows them. */
  deleteUser(channelId: string, userId: string): void {
    this.db.transaction(() => {
      this.db.query('DELETE FROM events WHERE channel_id = ? AND user_id = ?').run(channelId, userId);
      this.db.query('DELETE FROM channel_users WHERE channel_id = ? AND user_id = ?').run(channelId, userId);
      this.db.query('DELETE FROM users WHERE id = ? AND NOT EXISTS (SELECT 1 FROM channel_users WHERE user_id = ?)').run(userId, userId);
    })();
  }

  pruneRaw(now = Date.now()): number {
    return this.db.query('UPDATE events SET raw_json = NULL WHERE raw_json IS NOT NULL AND ts < ?').run(now - RAW_TTL_MS).changes;
  }

  private row(channelId: string, userId: string): Row | null {
    return this.db.query<Row, [string, string]>('SELECT * FROM channel_users WHERE channel_id = ? AND user_id = ?').get(channelId, userId);
  }
}
```

```ts
import type { KickEvent, Responder, UserContext, Utterance } from './types';
import { levelFor } from './loyalty';

/** Order matters: the first enabled trigger that fires is the one spoken. */
export type TemplateKey = 'level_up' | 'msg_milestone' | 'streak' | 'comeback' | 'first_message' | 'spam';
export type TemplateConfig = { enabled: boolean; variants: string[] };
type Vars = Record<string, string | number>;

// No suffix right after {user}: Azerbaijani suffixes depend on the name's vowels.
export const DEFAULT_TEMPLATES: Record<TemplateKey, TemplateConfig> = {
  level_up: { enabled: true, variants: ['Təbriklər, {user}! Yeni səviyyə: {level}.', '{user} artıq yeni səviyyədədir: {level}!'] },
  msg_milestone: { enabled: true, variants: ['{user} {n} mesaja çatdı!', 'Diqqət: {user} artıq {n} mesaj yazıb!'] },
  streak: { enabled: true, variants: ['{user} {streak} gündür ardıcıl buradadır!', '{streak} gün dalbadal! Sağ ol, {user}.'] },
  comeback: { enabled: true, variants: ['Kimləri görürük! {user} {days} gün sonra qayıtdı.', 'Xoş gördük, {user}! {days} gün idi görünmürdün.'] },
  first_message: { enabled: false, variants: ['Xoş gəldin, {user}!', 'Salam {user}, kanala xoş gəldin!'] },
  spam: { enabled: false, variants: ['{user}, klaviaturanı bir az dincə burax.', '{user}, sakit ol, hamı səni gördü.'] },
};

export const STREAK_MILESTONES = [3, 7, 14, 30];
export const MSG_MILESTONES = [100, 500, 1000, 5000];
export const COMEBACK_DAYS = 7;
export const SPAM_PER_MINUTE = 10;
export const GLOBAL_COOLDOWN_MS = 30_000;
const DAY = 86_400_000;

export const fill = (tpl: string, vars: Vars): string => tpl.replace(/\{(\w+)\}/g, (_, k: string) => String(vars[k] ?? ''));

export function triggers(e: KickEvent, ctx: UserContext): [TemplateKey, Vars][] {
  const p = ctx.prev;
  const out: [TemplateKey, Vars][] = [];
  if (ctx.level !== (p?.level ?? levelFor(0))) out.push(['level_up', { level: ctx.level.replace(/^\S+\s/, '') }]);
  if (e.type === 'chat' && MSG_MILESTONES.includes(ctx.msgCount) && (p?.msgCount ?? 0) < ctx.msgCount) out.push(['msg_milestone', { n: ctx.msgCount }]);
  if (p && ctx.streak !== p.streak && STREAK_MILESTONES.includes(ctx.streak)) out.push(['streak', { streak: ctx.streak }]);
  if (p && e.ts - p.lastSeen >= COMEBACK_DAYS * DAY) out.push(['comeback', { days: Math.floor((e.ts - p.lastSeen) / DAY) }]);
  if (e.type === 'chat' && (p?.msgCount ?? 0) === 0) out.push(['first_message', {}]);
  if (e.type === 'chat' && ctx.msgsLastMinute > SPAM_PER_MINUTE) out.push(['spam', {}]);
  return out;
}

export class TemplateResponder implements Responder {
  private fired = new Set<string>();
  private lastAt = -Infinity;

  constructor(
    private config: () => Record<TemplateKey, TemplateConfig>,
    private now: () => number = Date.now,
    private rand: () => number = Math.random,
  ) {}

  respond(e: KickEvent, ctx: UserContext): Utterance[] {
    const t = this.now();
    if (t - this.lastAt < GLOBAL_COOLDOWN_MS) return [];
    for (const [key, vars] of triggers(e, ctx)) {
      const cfg = this.config()[key];
      const id = `${ctx.userId}:${key}`;
      if (!cfg?.enabled || cfg.variants.length === 0 || this.fired.has(id)) continue;
      this.fired.add(id);
      this.lastAt = t;
      const tpl = cfg.variants[Math.floor(this.rand() * cfg.variants.length)];
      return [{ text: fill(tpl, { user: ctx.username, ...vars }), voice: 'announcer', priority: 2, kind: `template:${key}` }];
    }
    return [];
  }
}
```

```ts
  rewardAllowList: string; // comma-separated, empty = all

  bannedWords: string; // comma-separated

  voices: Record<VoiceSlot, string>; // '' = automatic

export const DEFAULT_SETTINGS: Settings = {
  username: '', channelId: '', chatroomId: '',
  readKicks: true, readRewards: true, rewardAllowList: '', readSubs: false, readChat: false,
  readUsername: true, maxLength: 200, bannedWords: '', caption: false,
  voices: { main: '', cyrillic: '', announcer: '' },
  templates: DEFAULT_TEMPLATES,
};

/** Validates untrusted input (settings file, dashboard POST) and applies it onto `base`. */
export function mergeSettings(raw: unknown, base: Settings = DEFAULT_SETTINGS): Settings {
  const out = structuredClone(base);
  if (!raw || typeof raw !== 'object') return out;
  const r = raw as Record<string, any>;
  for (const k of Object.keys(out) as (keyof Settings)[]) {
    if (k === 'voices' || k === 'templates') continue;
    if (typeof r[k] === typeof out[k]) (out as any)[k] = r[k];
  }
  if (!Number.isFinite(out.maxLength)) out.maxLength = base.maxLength;
  out.maxLength = Math.min(500, Math.max(20, Math.round(out.maxLength)));
  if (!/^\d*$/.test(out.channelId)) out.channelId = base.channelId;
  if (!/^\d*$/.test(out.chatroomId)) out.chatroomId = base.chatroomId;
  for (const slot of Object.keys(out.voices) as VoiceSlot[]) {
    if (typeof r.voices?.[slot] === 'string') out.voices[slot] = r.voices[slot];
  }
  for (const key of Object.keys(out.templates) as TemplateKey[]) {
    const t = r.templates?.[key];
    if (typeof t?.enabled === 'boolean') out.templates[key].enabled = t.enabled;
    if (Array.isArray(t?.variants)) {
      out.templates[key].variants = t.variants
        .filter((v: unknown): v is string => typeof v === 'string')
        .map((v: string) => v.trim())
        .filter(Boolean)
        .slice(0, 20);
    }
  }
  return out;
}
```

```ts
import type { KickEvent, UserContext } from './types';
import type { Settings } from './settings';
import { csv } from './text';

export const BOTS = new Set(['botrix', 'kickbot', 'kicklet', 'lumiastream', 'streamelements', 'nightbot', 'fossabot']);

/** hard = no template either (bots, blocked, the streamer). soft = the event is not read but templates may still fire. */
export type Skip = { reason: string; hard: boolean };

export function skipReason(e: KickEvent, ctx: UserContext, s: Settings): Skip | null {
  const name = e.username.toLowerCase();
  if (BOTS.has(name)) return { reason: 'bot', hard: true };
  if (ctx.blocked) return { reason: 'bloklanıb', hard: true };
  if (s.username && name === s.username.toLowerCase()) return { reason: 'streamerin öz mesajı', hard: true };
  switch (e.type) {
    case 'chat':
      if ((e.text ?? '').trimStart().startsWith('!')) return { reason: 'əmr (!)', hard: false };
      return s.readChat ? null : { reason: 'chat söndürülüb', hard: false };
    case 'reward': {
      if (!s.readRewards) return { reason: 'channel points söndürülüb', hard: false };
      const allow = csv(s.rewardAllowList);
      return allow.length && !allow.includes((e.rewardTitle ?? '').toLowerCase()) ? { reason: 'reward siyahıda yoxdur', hard: false } : null;
    }
    case 'kicks':
      return s.readKicks ? null : { reason: 'KICK söndürülüb', hard: false };
    case 'sub':
    case 'giftsub':
      return s.readSubs ? null : { reason: 'abunəlik söndürülüb', hard: false };
  }
}
```

```ts
export class DirectResponder implements Responder {
```

```ts
export type QueueItem = {
  id: string;
  text: string;
  voiceId: string;
  priority: 1 | 2 | 3; // 1 paid, 2 template, 3 chat
  kind: string;
  eventId: number; // -1 when not tied to a stored event (e.g. Test)
  username: string;
};

export class SpeechQueue {
  private items: QueueItem[] = [];

  constructor(private max = 15) {}

  get size(): number {
    return this.items.length;
  }

  /** Adds an item; returns the one dropped to stay under the limit. Priority 1 is never counted or dropped. */
  push(item: QueueItem): QueueItem | null {
    this.items.push(item);
    if (this.items.filter((i) => i.priority !== 1).length <= this.max) return null;
    for (const p of [3, 2] as const) {
      const idx = this.items.findIndex((i) => i.priority === p);
      if (idx >= 0) return this.items.splice(idx, 1)[0];
    }
    return null;
  }

  unshift(item: QueueItem): void {
    this.items.unshift(item);
  }

  next(): QueueItem | undefined {
    if (this.items.length === 0) return undefined;
    const best = Math.min(...this.items.map((i) => i.priority));
    return this.items.splice(this.items.findIndex((i) => i.priority === best), 1)[0];
  }
}
```

```ts
import { rm } from 'node:fs/promises';
import type { QueueItem, SpeechQueue } from './queue';

export type Playing = QueueItem & { file: string };
export type Output = { connected(): boolean; play(p: Playing): void; stop(): void };
export type Result = 'spoken' | 'failed' | 'dropped' | 'skipped';
export type Done = (item: QueueItem, result: Result, reason?: string) => void;

/** Plays one item at a time: synth → overlay plays it → overlay says "ended" → next. */
export class Player {
  current: Playing | null = null;
  paused = false;
  private busy = false;
  private watchdog: ReturnType<typeof setTimeout> | undefined;

  constructor(
    private queue: SpeechQueue,
    private synth: (item: QueueItem) => Promise<string>,
    private out: Output,
    private done: Done,
    private timeoutMs = 60_000,
  ) {}

  enqueue(item: QueueItem): void {
    const dropped = this.queue.push(item);
    if (dropped) this.done(dropped, 'dropped', 'növbə dolu');
    void this.pump();
  }

  async pump(): Promise<void> {
    if (this.current || this.busy || this.paused || !this.out.connected()) return;
    const item = this.queue.next();
    if (!item) return;
    this.busy = true;
    let file: string | null = null;
    try {
      file = await this.synth(item);
    } catch (err) {
      this.done(item, 'failed', err instanceof Error ? err.message : String(err));
    } finally {
      this.busy = false;
    }
    if (!file) return this.pump();
    if (this.paused || !this.out.connected()) {
      this.queue.unshift(item);
      await rm(file, { force: true });
      return;
    }
    this.current = { ...item, file };
    this.out.play(this.current);
    this.watchdog = setTimeout(() => this.ended(item.id), this.timeoutMs);
  }

  ended(id: string, result: Result = 'spoken'): void {
    const c = this.current;
    if (!c || c.id !== id) return;
    clearTimeout(this.watchdog);
    this.current = null;
    this.done(c, result);
    void rm(c.file, { force: true });
    void this.pump();
  }

  skip(): void {
    if (!this.current) return;
    this.out.stop();
    this.ended(this.current.id, 'skipped');
  }

  pause(): void {
    this.paused = true;
  }

  resume(): void {
    this.paused = false;
    void this.pump();
  }

  /** Last overlay closed: keep the current item for when OBS comes back. */
  disconnected(): void {
    const c = this.current;
    if (!c) return;
```

```ts
import type { Settings } from '../settings';
import type { VoiceSlot } from '../types';
import { hasCyrillic } from '../text';

export type Voice = { id: string; name: string; lang: string };

export interface VoiceEngine {
  listVoices(): Promise<Voice[]>;
  synth(text: string, voiceId: string, outFile: string): Promise<void>;
}

export function parseSayVoices(out: string): Voice[] {
  const seen = new Set<string>();
  const voices: Voice[] = [];
  for (const line of out.split('\n')) {
    const m = line.match(/^(.+?)\s+([a-z]{2,3}_[A-Za-z0-9]+)\s+#/);
    if (!m || seen.has(m[1])) continue;
    seen.add(m[1]);
    voices.push({ id: m[1], name: m[1], lang: m[2] });
  }
  return voices;
}

export function parseWinVoices(out: string): Voice[] {
  return out.split(/\r?\n/).flatMap((line) => {
    const [name, lang] = line.trim().split('|');
    return name && lang ? [{ id: name, name, lang }] : [];
  });
}

export function pickDefaults(voices: Voice[]): { main: string; cyrillic: string } {
  const main = voices.find((v) => v.lang.toLowerCase().startsWith('tr'))?.id ?? voices[0]?.id ?? '';
  const cyrillic = voices.find((v) => v.lang.toLowerCase().startsWith('ru'))?.id ?? main;
  return { main, cyrillic };
}

export function voiceFor(slot: VoiceSlot | undefined, text: string, s: Pick<Settings, 'voices'>, voices: Voice[]): string {
  const auto = pickDefaults(voices);
  const main = s.voices.main || auto.main;
  if (slot === 'announcer') return s.voices.announcer || main;
  if (slot === 'cyrillic' || hasCyrillic(text)) return s.voices.cyrillic || auto.cyrillic;
  return main;
}

/** Runs a command without a shell. Text never becomes part of a command line string. */
async function run(cmd: string[], opts: { stdin?: Response; env?: Record<string, string> } = {}): Promise<string> {
  const p = Bun.spawn(cmd, {
    stdin: opts.stdin ?? 'ignore',
    stdout: 'pipe',
    stderr: 'pipe',
    env: opts.env ? { ...process.env, ...opts.env } : undefined,
  });
  const [out, err, code] = await Promise.all([new Response(p.stdout).text(), new Response(p.stderr).text(), p.exited]);
  if (code !== 0) throw new Error(`${cmd[0]} exit ${code}: ${err.trim()}`);
  return out;
}

export class MacVoice implements VoiceEngine {
  async listVoices(): Promise<Voice[]> {
    return parseSayVoices(await run(['say', '-v', '?']));
  }

  async synth(text: string, voiceId: string, outFile: string): Promise<void> {
    // Text goes through stdin (-f -), so a message starting with "-" is never read as a flag.
    await run(['say', ...(voiceId ? ['-v', voiceId] : []), '--file-format=WAVE', '--data-format=LEI16@22050', '-o', outFile, '-f', '-'], {
      stdin: new Response(text),
    });
  }
}

const PS_LIST =
  "Add-Type -AssemblyName System.Speech; (New-Object System.Speech.Synthesis.SpeechSynthesizer).GetInstalledVoices() | Where-Object { $_.Enabled } | ForEach-Object { $_.VoiceInfo.Name + '|' + $_.VoiceInfo.Culture.Name }";
// Text is passed base64-encoded in an env var: no quoting issues, no injection, no console code-page problems.
const PS_SPEAK =
  'Add-Type -AssemblyName System.Speech; $s = New-Object System.Speech.Synthesis.SpeechSynthesizer; if ($env:KTTS_VOICE) { $s.SelectVoice($env:KTTS_VOICE) }; $s.SetOutputToWaveFile($env:KTTS_OUT); $s.Speak([Text.Encoding]::UTF8.GetString([Convert]::FromBase64String($env:KTTS_TEXT))); $s.Dispose()';
const ps = (script: string) => ['powershell.exe', '-NoProfile', '-NonInteractive', '-ExecutionPolicy', 'Bypass', '-Command', script];

export class WinVoice implements VoiceEngine {
  async listVoices(): Promise<Voice[]> {
    return parseWinVoices(await run(ps(PS_LIST)));
  }

  async synth(text: string, voiceId: string, outFile: string): Promise<void> {
    await run(ps(PS_SPEAK), {
      env: { KTTS_TEXT: Buffer.from(text, 'utf8').toString('base64'), KTTS_VOICE: voiceId, KTTS_OUT: outFile },
    });
  }
}

export const createVoiceEngine = (): VoiceEngine => (process.platform === 'win32' ? new WinVoice() : new MacVoice());
```

```ts
import { appendFileSync, existsSync, statSync } from 'node:fs';

/** Raw payloads of events we don't fully understand, so the parser can be fixed from real examples. */
export class UnknownLog {
  private counts = new Map<string, number>();

  constructor(private file: string, private perEvent = 5, private maxBytes = 5_000_000) {}

  write(event: string, channel: string, data: unknown): void {
    const n = this.counts.get(event) ?? 0;
    if (n >= this.perEvent) return;
    this.counts.set(event, n + 1);
    try {
      if (existsSync(this.file) && statSync(this.file).size > this.maxBytes) return;
      appendFileSync(this.file, JSON.stringify({ at: new Date().toISOString(), channel, event, data }) + '\n');
    } catch (err) {
      console.error('[unknown-log]', err);
    }
  }
}
```

```ts
import type { KickEvent, Responder, UserContext, Utterance } from './types';
import type { Store } from './db/store';
import type { Settings } from './settings';
import type { UnknownLog } from './unknown-log';
import { skipReason } from './filter';
import { levelFor } from './loyalty';
import { normalize, parseData, shortName, UNVERIFIED } from './kick/normalize';
import { safeText } from './safety';

export type LogEntry = {
  ts: number;
  username: string;
  type: string;
  text: string;
  status: 'queued' | 'skipped' | 'spoken' | 'failed' | 'dropped';
  reason?: string;
  kind?: string;
};

export type PipelineDeps = {
  store: Store;
  settings: () => Settings;
  direct: Responder;
  templates: Responder;
  enqueue: (u: Utterance, e: KickEvent, eventId: number) => void;
  log: (entry: LogEntry) => void;
  unknown: Pick<UnknownLog, 'write'>;
  channelKey: () => string;
};

const EMPTY = 'boş və ya qadağan mətn';

/** Used only when the DB write fails: speech must keep working. */
function blankContext(e: KickEvent): UserContext {
  return {
    userId: e.userId, username: e.username, level: levelFor(0), score: 0, msgCount: 0, daysActive: 0, streak: 0,
    firstSeen: e.ts, lastSeen: e.ts, kicksTotal: 0, subs: 0, giftSubs: 0, redemptions: 0, blocked: false,
    msgsLastMinute: 0, recentMessages: [], prev: null,
  };
}

export class Pipeline {
  constructor(private d: PipelineDeps) {}

  handleRaw(channel: string, event: string, data: unknown): void {
    const parsed = parseData(data);
    const e = normalize(event, parsed, this.d.channelKey());
    if (!e || UNVERIFIED.has(shortName(event))) this.d.unknown.write(event, channel, parsed);
    if (e) this.handle(e);
  }

  handle(e: KickEvent): void {
    const s = this.d.settings();
    let eventId = -1;
    let ctx: UserContext | null = null;
    try {
      ({ eventId, ctx } = this.d.store.record(e));
    } catch (err) {
      console.error('[db]', err);
    }
    const c = ctx ?? blankContext(e);
    const skip = skipReason(e, c, s);
    const out: Utterance[] = [];
    if (!skip) out.push(...this.d.direct.respond(e, c));
    if (ctx && !skip?.hard) out.push(...this.d.templates.respond(e, ctx));
    const safe = out.flatMap((u) => {
      const text = safeText(u.text, s);
      return text ? [{ ...u, text }] : [];
    });

    const base = { ts: e.ts, username: e.username, type: e.type, text: e.text ?? e.rewardTitle ?? '' };
    const reason = skip?.reason ?? (safe.length === 0 ? EMPTY : undefined);
    if (reason) {
      this.mark(eventId, reason);
      this.d.log({ ...base, status: 'skipped', reason });
    }
    for (const u of safe) {
      this.d.enqueue(u, e, eventId);
      this.d.log({ ...base, text: u.text, status: 'queued', kind: u.kind });
    }
  }

  private mark(eventId: number, reason: string): void {
    if (eventId < 0) return;
    try {
      this.d.store.markSpoken(eventId, false, reason);
    } catch (err) {
      console.error('[db]', err);
    }
  }
}
```

```ts
export async function getPusherCreds(fetchFn: typeof fetch = fetch): Promise<Creds> {
  try {
    const res = await fetchFn('https://web.kick.com/api/v1/realtime/connection', {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ client: { id: crypto.randomUUID(), type: 'web' }, capabilities: { accepted_providers: [{ provider: 'pusher' }] } }),
      signal: AbortSignal.timeout(10_000),
    });
    const json: any = await res.json();
    const c = json?.data?.connections?.find((x: any) => x?.provider === 'pusher')?.credentials;
    if (typeof c?.app_key === 'string' && typeof c?.cluster === 'string') return { key: c.app_key, cluster: c.cluster, fallback: false };
  } catch {
    // fall through to the fallback key
  }
  return { ...FALLBACK, fallback: true };
}

export const channelsFor = (channelId: string, chatroomId: string): string[] => [
  `chatrooms.${chatroomId}.v2`,
  `chatroom_${chatroomId}`,
  `channel_${channelId}`,
  `channel.${channelId}`,
];

export type SourceOptions = {
  channelId: string;
  chatroomId: string;
  onEvent: (channel: string, event: string, data: unknown) => void;
  onStatus: (s: SourceStatus) => void;
  creds?: () => Promise<Creds>;
  connect?: (url: string) => SocketLike;
};

const safeJson = (s: string): unknown => {
  try {
    return JSON.parse(s);
  } catch {
    return s;
  }
};

export class KickSource {
  private ws: SocketLike | null = null;
  private attempt = 0;
  private stopped = false;
  private fallback = false;
  private state: SourceStatus['state'] = 'disconnected';
  private timer: ReturnType<typeof setTimeout> | undefined;

  constructor(private o: SourceOptions) {}

  async start(): Promise<void> {
    this.stopped = false;
    const { key, cluster, fallback } = await (this.o.creds ?? (() => getPusherCreds()))();
    if (this.stopped) return;
    this.fallback = fallback;
    this.status('connecting');
    const url = `wss://ws-${cluster}.pusher.com/app/${key}?protocol=7&client=js&version=8.4.0&flash=false`;
    const ws = (this.o.connect ?? ((u: string) => new WebSocket(u) as unknown as SocketLike))(url);
    this.ws = ws;
    ws.onmessage = (m) => this.handle(String(m.data));
    ws.onerror = () => {}; // onclose follows and reconnects
    ws.onclose = () => {
      if (this.ws === ws) this.reconnect();
    };
  }

  stop(): void {
    this.stopped = true;
    clearTimeout(this.timer);
    const ws = this.ws;
    this.ws = null;
    ws?.close();
  }

  private handle(raw: string): void {
    let msg: { event?: unknown; channel?: unknown; data?: unknown };
    try {
      msg = JSON.parse(raw);
    } catch {
      return;
    }
    const event = typeof msg.event === 'string' ? msg.event : '';
    if (event === 'pusher:connection_established') {
      this.attempt = 0;
      for (const channel of channelsFor(this.o.channelId, this.o.chatroomId)) {
        this.send({ event: 'pusher:subscribe', data: { auth: '', channel } });
      }
      this.status('connected');
    } else if (event === 'pusher:ping') {
      this.send({ event: 'pusher:pong', data: {} });
    } else if (event === 'pusher:error') {
      const d: any = typeof msg.data === 'string' ? safeJson(msg.data) : msg.data;
      this.status(this.state, String(d?.message ?? JSON.stringify(d)));
    } else if (event && !event.startsWith('pusher')) {
      this.o.onEvent(typeof msg.channel === 'string' ? msg.channel : '', event, msg.data);
    }
  }

  private status(state: SourceStatus['state'], error?: string): void {
    this.state = state;
    this.o.onStatus({ state, error, fallbackKey: this.fallback });
  }

  private send(x: unknown): void {
    this.ws?.send(JSON.stringify(x));
  }

  private reconnect(): void {
    this.ws = null;
    if (this.stopped) return;
    this.status('disconnected');
    const delay = Math.min(30_000, 1000 * 2 ** this.attempt++);
    this.timer = setTimeout(() => {
      this.start().catch(() => this.reconnect());
    }, delay);
  }
}
```

```ts
      console.error('[voice] list failed', err);
      return [];

    // DOM and Bun both type setInterval; the cast keeps unref() without fighting the lib types.

    if (this.settings.channelId && this.settings.chatroomId) this.startSource();
  }

  private prune(): void {

      this.store.pruneRaw();
    } catch (err) {
      console.error('[db] prune', err);

    if (!this.settings.channelId || !this.settings.chatroomId) {
      const ids = await fetchChannelIds(this.settings.username);
      if (!ids) return { ok: false, needManual: true };
      this.updateSettings(ids);
    }
    this.startSource();
    return { ok: true };

      chatroomId: this.settings.chatroomId,

        this.pushStatus();

      next.chatroomId = '';

      kind: u.kind,
      eventId,
      username,

    return q.trim() ? this.store.search(this.channelKey, q.trim()) : this.store.top(this.channelKey, 20);
  }

    return this.store.profile(this.channelKey, userId);
  }

  deleteUser(userId: string): void {
    this.store.deleteUser(this.channelKey, userId);
  }

  setBlocked(userId: string, blocked: boolean): void {
    this.store.setBlocked(this.channelKey, userId, blocked);
  }

    this.pushStatus();

    const file = join(tmpdir(), `kicktts-${item.id}.wav`);
    try {
      await this.engine.synth(item.text, item.voiceId, file);
    } catch (err) {
      const fallback = voiceFor('main', '', this.settings, this.voices);
      if (!fallback || fallback === item.voiceId) throw err;
      await this.engine.synth(item.text, fallback, file);
    }
    return file;
  }

  private onDone(item: QueueItem, result: Result, reason?: string): void {
    const why = reason ?? (result === 'skipped' ? 'düymə ilə keçildi' : undefined);
    if (item.eventId >= 0) {
      try {
        this.store.markSpoken(item.eventId, result === 'spoken', result === 'spoken' ? null : why ?? result);
      } catch (err) {
        console.error('[db]', err);
      }
    }
    this.pushLog({ ts: Date.now(), username: item.username, type: item.kind, text: item.text, status: result, reason: why, kind: item.kind });
    this.pushStatus();
  }

    (ws.data.role === 'overlay' ? this.overlays : this.dashboards).add(ws);
    if (ws.data.role === 'overlay') void this.player.pump();
    this.pushStatus();
  }

  removeSocket(ws: Sock): void {
    const isOverlay = this.overlays.delete(ws);
    this.dashboards.delete(ws);
    if (isOverlay && this.overlays.size === 0) this.player.disconnected();
    this.pushStatus();
  }

  onSocketMessage(ws: Sock, raw: string): void {
    if (ws.data.role !== 'overlay') return;
    try {
      const msg = JSON.parse(raw);
      if (msg?.type === 'ended' && typeof msg.id === 'string') this.player.ended(msg.id);
    } catch {
      // ignore malformed overlay messages
    }
  }

  snapshot() {
    return { settings: this.settings, voices: this.voices, status: this.statusPayload(), log: this.logRing };
  }

  private statusPayload() {
    return {
      source: this.status,
      overlays: this.overlays.size,
      queue: this.queue.size,
      paused: this.player.paused,
      current: this.player.current?.text ?? null,
    };
  }

  private pushStatus(): void {
    this.toDashboards({ type: 'status', status: this.statusPayload() });
  }

  private pushLog(entry: LogEntry): void {
    this.logRing.unshift(entry);
    if (this.logRing.length > 100) this.logRing.length = 100;
    this.toDashboards({ type: 'log', entry });
  }

  private toOverlays(msg: unknown): void {
    const s = JSON.stringify(msg);
    for (const ws of this.overlays) ws.send(s);
  }

  private toDashboards(msg: unknown): void {
    const s = JSON.stringify(msg);
    for (const ws of this.dashboards) ws.send(s);
  }
}
```

```ts
import type { BunRequest, Server, ServerWebSocket } from 'bun';
import dashboard from '../web/dashboard.html';
import overlay from '../web/overlay.html';
import type { App, WsData } from './app';

const json = (data: unknown, status = 200) => Response.json(data, { status });
const noContent = () => new Response(null, { status: 204 });
const forbidden = () => new Response('Forbidden', { status: 403 });

/** Only this machine's own pages may call the API (blocks CSRF from other sites and DNS rebinding). */
function trusted(req: Request, port: number | undefined): boolean {
  const hosts = [`localhost:${port}`, `127.0.0.1:${port}`];
  if (!hosts.includes(req.headers.get('host') ?? '')) return false;
  const origin = req.headers.get('origin');
  return !origin || hosts.some((h) => origin === `http://${h}`);
}

function g<R extends Request>(fn: (req: R) => Response | Promise<Response>) {
  return (req: R, server: Server) => (trusted(req, server.port) ? fn(req) : forbidden());
}

const id = (req: BunRequest<'/api/users/:id'> | BunRequest<'/api/users/:id/block'>) => decodeURIComponent(req.params.id);

export function startServer(app: App, port = 7777) {
  return Bun.serve({
    hostname: '127.0.0.1',
    port,
    routes: {
      '/': dashboard,
      '/overlay': overlay,
      '/api/state': g(() => json(app.snapshot())),
      '/api/settings': { POST: g(async (req) => json(app.updateSettings(await req.json().catch(() => ({}))))) },
      '/api/connect': { POST: g(async () => json(await app.connect())) },
      '/api/test': {
        POST: g(async (req) => {
          const b: any = await req.json().catch(() => ({}));
          app.test(['main', 'cyrillic', 'announcer'].includes(b?.slot) ? b.slot : 'main');
          return noContent();
        }),
      },
      '/api/skip': { POST: g(() => (app.player.skip(), noContent())) },
      '/api/pause': { POST: g(() => (app.player.pause(), app.refresh(), noContent())) },
      '/api/resume': { POST: g(() => (app.player.resume(), app.refresh(), noContent())) },
      '/api/users': g((req) => json(app.users(new URL(req.url).searchParams.get('q') ?? ''))),
      '/api/users/:id': {
        GET: g((req: BunRequest<'/api/users/:id'>) => {
          const p = app.profile(id(req));
          return p ? json(p) : json({ error: 'not found' }, 404);
        }),
        DELETE: g((req: BunRequest<'/api/users/:id'>) => (app.deleteUser(id(req)), noContent())),
      },
      '/api/users/:id/block': {
        POST: g(async (req: BunRequest<'/api/users/:id/block'>) => {
          const b: any = await req.json().catch(() => ({}));
          app.setBlocked(id(req), b?.blocked === true);
          return noContent();
        }),
      },
      '/audio/:id': g((req: BunRequest<'/audio/:id'>) => {
        const c = app.player.current;
        return c && c.id === req.params.id
          ? new Response(Bun.file(c.file), { headers: { 'content-type': 'audio/wav', 'cache-control': 'no-store' } })
          : new Response('Not found', { status: 404 });
      }),
    },
    fetch(req, server) {
      if (new URL(req.url).pathname === '/ws') {
        if (!trusted(req, server.port)) return forbidden();
        const role = new URL(req.url).searchParams.get('role') === 'overlay' ? 'overlay' : 'dashboard';
        if (server.upgrade(req, { data: { role } satisfies WsData })) return;
        return new Response('Upgrade failed', { status: 400 });
      }
      return new Response('Not found', { status: 404 });
    },
    websocket: {
      open: (ws) => app.addSocket(ws as ServerWebSocket<WsData>),
      message: (ws, msg) => app.onSocketMessage(ws as ServerWebSocket<WsData>, String(msg)),
      close: (ws) => app.removeSocket(ws as ServerWebSocket<WsData>),
    },
  });
}
```

```ts
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { Store } from '../src/db/store';
import { fetchChannelIds } from '../src/kick/channel';
import { normalize, parseData, shortName } from '../src/kick/normalize';
import { KickSource } from '../src/kick/realtime';
import { Pipeline } from '../src/pipeline';
import { DirectResponder } from '../src/responders';
import { mergeSettings } from '../src/settings';
import { TemplateResponder } from '../src/templates';
import { createVoiceEngine, voiceFor } from '../src/voice/os';

async function pickLive(): Promise<string> {
  try {
    const r = await fetch('https://kick.com/stream/livestreams/en?page=1&limit=3&sort=desc', {
      headers: { accept: 'application/json', 'user-agent': 'Mozilla/5.0' },
      signal: AbortSignal.timeout(10_000),
    });
    const slug = ((await r.json()) as any)?.data?.[0]?.channel?.slug;
    if (typeof slug === 'string') return slug;
  } catch {
    // fall back below
  }
  return 'xqc';
}

const username = process.argv[2] ?? (await pickLive());
const ids = await fetchChannelIds(username);
if (!ids) {
  console.error(`FAIL: ${username} üçün kanal ID-ləri alınmadı`);
  process.exit(1);
}
console.log('kanal:', username, ids);

const settings = mergeSettings({ username: 'smoke-test-nobody', ...ids, readChat: true });
const counts = new Map<string, number>();
const samples: string[] = [];
let queued = 0;

const pipeline = new Pipeline({
  store: new Store(),
  settings: () => settings,
  direct: new DirectResponder(() => settings),
  templates: new TemplateResponder(() => settings.templates),
  enqueue: (u) => {
    queued++;
    if (samples.length < 3) samples.push(u.text);
  },
  log: () => {},
  unknown: { write: (ev, _ch, d) => console.log('[unknown]', ev, JSON.stringify(d).slice(0, 300)) },
  channelKey: () => `kick:${ids.channelId}`,
});

const src = new KickSource({
  ...ids,
  onEvent: (ch, ev, data) => {
    const name = shortName(ev);
    counts.set(name, (counts.get(name) ?? 0) + 1);
    if (name === 'RewardRedeemedEvent') console.log('[reward]', normalize(ev, parseData(data), 'kick:x'));
    pipeline.handleRaw(ch, ev, data);
  },
  onStatus: (s) => console.log('[status]', s),
});

await src.start();
await Bun.sleep(60_000);
src.stop();

console.log('event sayları:', Object.fromEntries(counts));
console.log(`oxunmaq üçün növbəyə düşən: ${queued}`, samples);

const engine = createVoiceEngine();
const voices = await engine.listVoices();
for (const [i, text] of samples.entries()) {
  const out = join(tmpdir(), `kicktts-smoke-${i}.wav`);
  await engine.synth(text, voiceFor(undefined, text, settings, voices), out);
  console.log('wav:', out, Bun.file(out).size, 'bytes');
}

if (!counts.get('ChatMessageEvent') || queued === 0) {
  console.error('FAIL: chat gəlmədi və ya oxunmaq üçün növbəyə düşmədi');
  process.exit(1);
}
console.log('OK');
```

## Known risks to report after execution

- **Windows voices (not verifiable on this Mac):** `System.Speech` only lists SAPI5 "Desktop" voices. Turkish voices added through Windows Settings are often OneCore-only and invisible to it. If the Turkish voice is missing on a real Windows PC, the follow-up is a WinRT (`Windows.Media.SpeechSynthesis`) engine behind the same `VoiceEngine` interface.
- **Unverified Kick events:** `KicksGifted` and the three subscription events are parsed defensively. Their first 5 real payloads per session land in `unknown-events.log` and should be used to tighten `normalize.ts`.
- **`localhost` vs `127.0.0.1`:** the server binds IPv4 only. Chrome and OBS fall back from `::1` to `127.0.0.1` automatically; a client that does not would need `http://127.0.0.1:7777/overlay`.
- **No silent-connection watchdog:** if the network drops without a WebSocket close, the source stays "connected" until the OS times out the socket.
